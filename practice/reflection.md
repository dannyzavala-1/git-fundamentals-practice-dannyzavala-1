# Git workflow reflection

Write at least one complete sentence for each answer. Each answer must contain at least 20 characters.

## 1. What is the difference between a commit and a push?

Answer: A commit saves my changes to a local repository and leaves a message of the changes I made. A push uploads the local repository to a remote one so other people can access it.

## 2. Why work on a branch instead of directly on `main`?

Answer: A branch keeps work I do seperate from the main project, so if I mess up it doesn't mess up the main project.

## 3. What does a pull request make possible?

Answer: A pull request lets others check my changes/work and comment or request fixes.

## 4. Which Git command helped you understand the repository's state, and what did it show you?

Answer: 'git status' helps me understand my repositorys state.
